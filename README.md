# تطبيق وسيط لحجز مواعيد الأطباء

منصة تربط المريض بالطبيب: بحث حسب المحافظة والتخصص، أوقات متاحة حقيقية، حجز مثبّت، وتذكير قبل الموعد.

## القرارات المعتمدة

| القرار | الاختيار |
|---|---|
| الدولة | العراق — ١٩ محافظة |
| نقطة البداية | تطبيق جوال أولاً |
| نمط الحجز | النمطان معاً: موعد بوقت محدد **و** رقم دور، يختار الطبيب |
| الخادم وقاعدة البيانات | Node + PostgreSQL + Prisma |
| تطبيق المريض | React Native + Expo (بدل Flutter، لتبقى المنظومة بلغة واحدة) |
| لوحات الطبيب والسكرتير والإدارة | Next.js — لأن السكرتير يعمل على حاسوب في العيادة |
| الدفع الإلكتروني | مؤجَّل للمرحلة الثانية |

## الحالة

| المرحلة | الحالة |
|---|---|
| ١ — الأساس والمواقع | ✅ منجزة |

## ما هو منجز

**نموذج بيانات كامل** (`api/prisma/schema.prisma`) يغطي المواقع، المستخدمين والأدوار الأربعة،
الأطباء والتخصصات، العيادات والممارسات، قوالب الدوام واستثناءاته، المواعيد بنمطيها، التقييمات،
قائمة الانتظار، الإشعارات، وسجل العمليات.

**بيانات العراق المرجعية**: ١٩ محافظة، ١١٨ قضاءً، ٥٢ حياً في المدن الكبرى، و٢٨ تخصصاً طبياً
مع أسمائها الشائعة (ليجد المريض «طبيب أطفال» و«اختصاص أطفال» بنفس البحث).

**الحماية من الحجز المزدوج** مطبَّقة على مستوى قاعدة البيانات ومُختبَرة — راجع
[منع الحجز المزدوج](#منع-الحجز-المزدوج).

## التشغيل

```bash
cd api
npm install
cp .env.example .env          # ثم عدّل DATABASE_URL
npm run db:push               # إنشاء الجداول
npm run db:seed               # تعبئة المحافظات والأقضية والتخصصات
npm run verify:booking        # التحقق من منع الحجز المزدوج
```

## منع الحجز المزدوج

إذا حجز مريضان نفس الوقت مرة واحدة أمام طبيب، تفقد الطبيب. التحقق في الكود لا يكفي: بين قراءة
«هذا الوقت فارغ» وكتابة الحجز فجوة تمرّ منها ضغطتان متزامنتان.

الحماية قيد فريد على `(doctorClinicId, slotStart, queueNumber, lockKey)`. الحقل `lockKey` يساوي
`true` ما دام الحجز يشغل المكان، ويصبح `NULL` عند الإلغاء — وبما أن بوستغرس يعتبر قيم `NULL`
مختلفة في القيود الفريدة، يتحرر المكان لغيره بينما يبقى صف الحجز الملغى محفوظاً في السجل.

`npm run verify:booking` يثبت ذلك على قاعدة حقيقية:

```
✔ نمط الوقت المحدد يرفض حجز نفس الفترة مرتين
✔ الإلغاء يحرّر الفترة ويُبقي سجل الملغى
✔ نمط رقم الدور يرفض تكرار نفس الرقم ويقبل التالي
✔ ست محاولات متزامنة ⇒ حجز واحد فقط ينجح
```

## ملاحظات

- التقسيمات الإدارية تتغير — راجع قوائم الأقضية قبل الإطلاق. كلها قابلة للتعديل من لوحة الإدارة
  دون لمس الكود.
- الأوقات كلها تُخزَّن بتوقيت عالمي وتُعرض بتوقيت العيادة (`Asia/Baghdad` افتراضاً).
- لا يخزّن النظام تشخيصات ولا تقارير طبية — هو وسيط حجز فقط، وهذا قرار مقصود يبقي الالتزامات
  القانونية والأمنية في حدودها.
