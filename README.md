# تطبيق وسيط لحجز مواعيد الأطباء

منصة تربط المريض بالطبيب: بحث حسب المحافظة والتخصص، أوقات متاحة حقيقية، حجز مثبّت، وتذكير قبل الموعد.

## القرارات المطلوبة قبل كتابة الكود

1. الدولة المستهدفة (لتجهيز قائمة المحافظات والأقضية الحقيقية)
2. ويب أولاً أم تطبيق جوال أولاً
3. نمط الحجز: موعد بوقت محدد أم رقم دور
4. هل يدخل الدفع الإلكتروني في النسخة الأولى
5. لغة/إطار العمل المفضّل
