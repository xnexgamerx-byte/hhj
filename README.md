# تطبيق وسيط لحجز مواعيد الأطباء

منصة تربط المريض بالطبيب: بحث حسب المحافظة والتخصص، أوقات متاحة حقيقية، حجز مثبّت،
و**تفاصيل كل حجز تصل واتساب الطبيب فور إتمامه**.

## القرارات المعتمدة

| القرار | الاختيار |
|---|---|
| الدولة | العراق — ١٩ محافظة |
| نقطة البداية | تطبيق جوال أولاً |
| نمط الحجز | النمطان معاً: موعد بوقت محدد **و** رقم دور، يختار الطبيب |
| الخادم وقاعدة البيانات | Node + Fastify + PostgreSQL + Prisma |
| تطبيق المريض | React Native + Expo |
| لوحات المالك والطبيب والسكرتير | Next.js |
| تسجيل الأطباء | **المالك وحده** — لا تسجيل ذاتي |
| إشعار الطبيب | واتساب عبر WhatsApp Cloud API |
| الدفع الإلكتروني | مؤجَّل للمرحلة الثانية |

## الحالة

## مساران للدخول، لا مسار واحد

```
المريض                    رقم هاتف + رمز تحقق، بلا باسوورد إطلاقاً
الطبيب والسكرتير والمالك   إيميل + باسوورد ينشئهما المالك
```

**لا يوجد تسجيل ذاتي للأطباء.** المالك ينشئ الحساب فيُولَّد باسوورد أولي يظهر له مرة
واحدة ليسلّمه للطبيب، ثم يُلزَم الطبيب بتغييره أول دخول قبل أن يستطيع فعل أي شيء —
وإلا بقي باسوورد يعرفه شخصان. أثر جانبي مفيد: كل طبيب على المنصة موثّق بحكم أن المالك
أدخله بنفسه، وهذا أقوى في بناء الثقة من مراجعة وثائق يرفعها مجهول.

## تحويل الحجز إلى واتساب الطبيب

فور إتمام المريض بياناته تُرسل تفاصيل الحجز إلى رقم واتساب الطبيب:

```
🗓 حجز جديد

المريض: علي حسن
الهاتف: 0770 998 8776
الموعد: الأحد، ٦ أيلول ٢٠٢٦ — الدور ١ بين ٤:٠٠ م و٧:٠٠ م
العيادة: عيادة النور للأطفال
الرقم المرجعي: EK9-ELJ

ملاحظة المريض: الطفل عنده حرارة منذ يومين
```

**فشل الواتساب لا يُفشل الحجز.** الرسالة تُسجَّل صفاً في `notification_logs` ثم تُرسل بعد
نجاح الحجز؛ إن سقط الإرسال بقيت في الطابور لإعادة المحاولة، ولم يخسر المريض موعده لأن
واتساب كان متعطلاً.

### ما يلزم لتشغيل الإرسال الحقيقي

الطريق الرسمي الوحيد هو **WhatsApp Cloud API** من ميتا، ويتطلب:

1. حساب Meta Business موثّق
2. **رقم هاتف مخصص للـ API** — لا يعود صالحاً لتطبيق واتساب العادي بعد ربطه
3. اعتماد قالبَي `new_booking` و`booking_cancelled` من ميتا بالعربية — واتساب لا يسمح
   بإرسال نص حر لمن لم يراسلك خلال ٢٤ ساعة، والطبيب لن يراسل المنصة أصلاً
4. تعيين `WHATSAPP_TOKEN` و`WHATSAPP_PHONE_NUMBER_ID`

بدون هذه المتغيرات يعمل مزوّد بديل يطبع الرسالة في الطرفية مع رابط `wa.me` جاهز — يصلح
للتطوير وكحل يدوي مؤقت.

> المكتبات غير الرسمية (`whatsapp-web.js` وأمثالها) تخالف شروط واتساب وتؤدي إلى حظر
> الرقم. لم تُستعمل ولا يُنصح بها.

## التشغيل

```bash
cd api
npm install
cp .env.example .env
# عيّن DATABASE_URL وJWT_SECRET وOWNER_EMAIL وOWNER_PASSWORD
npm run db:push      # إنشاء الجداول
npm run db:seed      # المحافظات والأقضية والتخصصات + حساب المالك الأول
npm run dev          # الخادم على المنفذ ٣٠٠٠
npm run verify       # فحص الأنواع + ١٨ اختباراً
```

## منع الحجز المزدوج

إذا حجز مريضان نفس الوقت مرة واحدة أمام طبيب، تفقد الطبيب. التحقق في الكود لا يكفي: بين
قراءة «هذا الوقت فارغ» وكتابة الحجز فجوة تمرّ منها ضغطتان متزامنتان.

الحماية قيد فريد على `(doctorClinicId, slotStart, queueNumber, lockKey)`. الحقل `lockKey`
يساوي `true` ما دام الحجز يشغل المكان، ويصبح `NULL` عند الإلغاء — وبما أن بوستغرس يعتبر
قيم `NULL` مختلفة في القيود الفريدة، يتحرر المكان لغيره بينما يبقى صف الحجز الملغى
محفوظاً في السجل.

## التحقق

`npm run verify` — فحص أنواع + ١٨ اختباراً على قاعدة بيانات حقيقية:

```
الحجز المزدوج (٤)
  ✔ نمط الوقت المحدد يرفض حجز نفس الفترة مرتين
  ✔ الإلغاء يحرّر الفترة ويُبقي سجل الملغى
  ✔ نمط رقم الدور يرفض تكرار نفس الرقم ويقبل التالي
  ✔ ست محاولات متزامنة ⇒ حجز واحد فقط ينجح

حسابات المالك والواتساب (١٤)
  ✔ كل صيغ الرقم العراقي تُطبَّع إلى صيغة واحدة
  ✔ رقم الهاتف يُعرض بصيغة عراقية مقروءة وقابلة للنقر
  ✔ المالك ينشئ حساب الطبيب بإيميل وباسوورد أولي
  ✔ الباسوورد لا يُخزَّن نصاً في قاعدة البيانات
  ✔ الطبيب يدخل بالباسوورد الأولي ويُطلب منه تغييره
  ✔ بعد التغيير يدخل بالباسوورد الجديد ولا يعمل القديم
  ✔ الحساب يُقفل مؤقتاً بعد خمس محاولات فاشلة
  ✔ إعادة تعيين الباسوورد من المالك تفك القفل وتُلزم بتغيير جديد
  ✔ تفاصيل الحجز تُرسل لواتساب الطبيب
  ✔ وسائط القالب خالية من الأسطر الجديدة
  ✔ تعطّل واتساب لا يُفشل الحجز
  ✔ إعادة المحاولة توصّل ما سقط
  ✔ إيقاف الواتساب لطبيب يمنع الإرسال دون تعطيل الحجز
  ✔ المزوّد الاحتياطي يسجّل الرسالة ويعطي رابط wa.me
```

## ملاحظات

- التقسيمات الإدارية تتغير — راجع قوائم الأقضية قبل الإطلاق. كلها قابلة للتعديل من لوحة
  المالك دون لمس الكود.
- أرقام الهواتف تُقبل بكل صيغها (`07701234567` · `+9647701234567` · `٠٧٧٠١٢٣٤٥٦٧`)
  وتُخزَّن بصيغة واحدة — وإلا تكرر الحساب الواحد بأشكال مختلفة.
- الأوقات كلها تُخزَّن بتوقيت عالمي وتُعرض بتوقيت العيادة (`Asia/Baghdad`).
- لا يخزّن النظام تشخيصات ولا تقارير طبية — وسيط حجز فقط، وهذا قرار مقصود.
- `npm audit` يبلّغ عن ثغرة في `deepmerge-ts` عبر أداة Prisma السطرية. هي اعتمادية
  تطوير لا تدخل الإنتاج، ولا تتوفر نسخة مصحَّحة بعد.
